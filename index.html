Design by hand,

Code using AI

Design should feel human, as it’s built to service humans. It’s easy to understand why the advent of AI might strike a chord with designers; it’s a literal problem-solving machine. Despite this, a human hand in design will always be necessary, as a machine cannot understand how a design feels when used by a human. After studying design and exploring the potential of AI tools, I’ve come to understand that there is a happy medium for designers when it comes to using AI. While it’s easy to just vibecode an entire project; process to prototype, the product will turn out messy and ugly. When designed by hand, you’ll get a great product; but maybe not reaching the full potential of what it could be.

Design

Deeper

This tool looks to help UI designers understand how they can use the power of AI to turn a Figma prototype into an interactive app. Let’s say, for example, you’re designing an online card game. You have the vector files, stylesheets, and a pretty good Figma prototype, but simulation of gameplay is a function that cannot be built out in Figma, so the real user experience isn’t quite replicated. This is where I teach you how to upgrade your existing prototype to something that closer represents the MVP. All this will take is some basic knowledge of html, css, and js.

Studio

This tool helps visualize how an AI assistant writes your styles. Each variable connects to a different aspect of the card game preview. See how changing variables in css affects the design as a whole.

Tools

Talking

My process combines the powers of Figma, Claude, and VSCode. Figma allows designers to execute their vision explicitly in a pixel perfect format, a great step from a sketch to a structure. With the Figma MCP (Model Context Protocol), an AI assistant can read that structure directly, translating decisions into code without losing visual fidelity. This brings your design vision to the platform it will live in an MVP.

Figma

MCP

Once set up, the Figma MCP server allows direct translation from your mockup to your code editor. Think of the MCP as a cellular network that lets the tools speak to each other. This interactive shows prompts you can use to extract specific elements from your design, which can be combined to bring your design to life! It is important to note that for this to work you must have Figma open, and the frames you reference selected.

Language

            
Now that you know how to get the AI to translate your design, the next interactive teaches how to understand what it generates. Through the MCP server, your styles become design variables. These styles can be called throughout the css with the value var(--color). It is important to understand how the generated code works so that if you want to change something later you can do it yourself. This is most important for designers with the css code, but for those more interested in learning how the interactions work, asking your LLM to explain each function in the javascript can expand your understanding (and your prompts)!

Build

            
Better

            
AI certainly has its place in design, but its not as simple as commanding a machine to do what you want. Building a network between VS Code, an AI assistant, and Figma takes a little time to set up and get used to, but the result allows you to maintain your design vision and still utilize AI coding tools to elevate your prototype. Below I've linked my source for Figma MCP info, some more tips on troubleshooting with the MCP, and a bonus interactive ;) Happy coding!

            
            

              
Working with the MCP won't be an automatic process. If things aren't looking right, try building component by component until you can import the full design. If you get stuck, screenshots seem to work very well as the pixel amounts will match the Figma design. What's most important is that you have a clear vision as a designer, and you can articulate how you want the design to work to your assistant. The more detail in your prompt, the better the output!
